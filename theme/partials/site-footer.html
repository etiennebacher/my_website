{# Overrides the shared footer partial so a footer label can carry inline markup — needed for "Made with Calepin", where only the word "Calepin" should be a link. Calepin's footer schema has no way to express that: an item is `label` plus an optional `target`, and the whole label becomes the link text. Nor can the markup be smuggled through the config, because Calepin HTML-escapes `label` before the template sees it (`item.label_html` is likewise pre-rendered — that is how `{icon:...}` labels become SVG), and it rejects unknown keys, so a companion field such as `prefix` will not parse. What is left is to reverse that escaping here, for text rows only. `&` is undone last so an escaped entity is not decoded twice.
